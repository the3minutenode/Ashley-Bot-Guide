# Ashley: community bot guide

> Information only. This repository documents how **Ashley**, the community bot of
> **The 3-Minute Node Vault** Discord server (the ComfyUI YouTube channel), behaves from a member's
> point of view. It contains **no source code, configuration, IDs or credentials**.

Ashley welcomes newcomers, rewards participation with XP and levels, and quietly removes spam.
This guide explains what she does and how to level up.

## The short version

1. **Introduce yourself once** in the introduction channel. A real message (where you're from, what
   you make, or an image with a caption) earns **35 XP**, which takes you straight to **level 2** and
   unlocks the workflow downloads.
2. **Keep taking part.** Chatting, sharing results in the showcase, helping others in the help forum
   and getting reactions all add XP.
3. **Level up for roles.** Level 2 = **Member**, level 5 = **Sampler**, level 10 = **Checkpoint**.
4. **Check progress any time** with `/rank` (or the **My progress** button) in the introduction
   channel. Only you can see the answer.

## XP at a glance

| Action | XP |
|---|---|
| A real message | 10 |
| An image in the showcase channel | +15 |
| A reply in someone else's help thread | +15 |
| Giving a reaction (Members only) | 2 |
| Receiving a reaction (from a Member) | 3 |
| First valid introduction (one time) | +25 |

Each action has a cooldown so spamming does not help. Full rules in [How XP works](docs/xp-and-levels.md).

## Scope and accuracy

- Numbers describe the live bot as of **version 2.4.3 (November 2026)**. Server staff can tune them,
  so treat this as a guide, not a contract.
- Staff-only tools (moderation, XP adjustments, reports) exist but are not documented here.
- Found a mistake? Open an issue.
